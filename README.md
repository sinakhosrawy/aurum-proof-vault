# Aurum Proof Vault

سلام و درود من یک وب سایت خیلی حرفه ای میخوام که برای یک مشتریم طلا ساز است و میخواهد طلایی که میسازد و کدی برای اون طلا در نظر میگیره را داخل اون سایت که پنل مدیریت داشته باشه ثبت میکنه بعد یک جواب هم براش به طور مثال یک طلا اب شده کرده کد ۱۰۰۴۲ براش تعریف میکنه بعد برای اون مشتری خودش که  طلا را میفرسته اون مشتری برای ان که استعلام اون طلا را بگیره داخل وب سایتح این طلا ساز که بفهمه ایا این طلاش کدی که روی طلا است مثال ۱۰۰۴۲ جوابش را رابگیره مثلا طلا ساز تعریف میکنه که این طلا با کد ۱۰۰۴۲ که کد جوابش هم ثبت کنه برای این طلا که میشه مثلا ۷۷۵

این جواب ۷۷۵ به مشتری نشون بده بعد رهگیری کد طلاش با خوشکلترین دیزاین و شهر سقز اهل کردستان است بهترین طلا ساز شهرستان سقز
